# Keycloak

Realm importable, client public OIDC/PKCE S256, audience meteosentinel-api. Aucun mot de passe utilisateur versionné. Créer les comptes manuellement après revue. Le portail S4 local ne réalise pas de connexion OIDC ; cette intégration fait partie du développement après validation. Docker utilise start-dev pour le laboratoire, pas une configuration de production.
